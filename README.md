# React Task Manager

A modern and responsive Task Manager application built with React.  
The application allows users to create, organize, search, filter, and manage tasks efficiently with a clean and user-friendly interface.

## 🚀 Features

- ✅ Add new tasks
- ✅ Mark tasks as completed
- ✅ Delete tasks
- ✅ Filter tasks by All, Active, and Completed
- ✅ Search tasks by task name or category
- ✅ Sort tasks
- ✅ Set task priority
- ✅ Add task categories
- ✅ Set due dates
- ✅ Task statistics dashboard
- ✅ Active and completed task count
- ✅ Task completion progress
- ✅ Dark Mode
- ✅ Local Storage for saving tasks
- ✅ Reusable React components
- ✅ Responsive user interface

## 🛠️ Technologies Used

- **React.js**
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**
- **React Hooks**
- **Context API**
- **Custom Hooks**
- **Local Storage**
